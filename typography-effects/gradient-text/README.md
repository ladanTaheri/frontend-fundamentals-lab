# Gradient Text
A typography effect example featuring gradient-filled text built with HTML and CSS.

## Features

- Linear gradient text effect
- Background clipping with text
- Transparent text rendering
- Modern typography styling
- Responsive font sizing

## Technologies

- HTML5
- CSS3

## Overview
This example demonstrates how to create a modern gradient text effect using CSS `linear-gradient`, `background-clip: text`, and transparent text rendering techniques. It is commonly used in hero sections, landing pages, branding, and modern UI designs.
